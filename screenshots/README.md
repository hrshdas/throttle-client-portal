# Application Screenshots

This directory contains application interface screenshots for documentation and presentation purposes.

## Screenshots Directory Structure

Place screenshots in this folder using the following naming convention:

* `dashboard.png` — Analytics & Campaign Overview Dashboard
* `tasks-and-approvals.png` — Task & Approvals Review Engine
* `create-task-modal.png` — Interactive Task Creation Modal
* `encrypted-chat.png` — Client-Agency Encrypted Chat Interface
* `meta-connection-modal.png` — Meta Ad Account OAuth & Connection Dialog
* `login-page.png` — User Login & Registration Interface

> **Note:** Embed screenshots in `README.md` using:

> ```
