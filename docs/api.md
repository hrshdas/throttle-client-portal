# API Endpoint Reference

All API endpoints are relative to `http://localhost:8000/api/v1` (or your production API URL).

> **Swagger / OpenAPI Documentation:**  
> Interactive API documentation is automatically generated by FastAPI and accessible locally at `http://localhost:8000/docs`.

---

## 1. Authentication Endpoints

### `POST /api/v1/auth/register`
Creates a new organization and client admin account.
- **Request Body:**
  ```json
  {
    "name": "Jane Doe",
    "email": "jane@acme.com",
    "password": "Password123!",
    "company_name": "Acme Corp"
  }
  ```
- **Response (200 OK):**
  ```json
  {
    "access_token": "eyJhbGciOi...",
    "refresh_token": "eyJhbGciOi...",
    "token_type": "bearer",
    "user": {
      "id": "d497df7b...",
      "name": "Jane Doe",
      "email": "jane@acme.com",
      "role": "CLIENT_ADMIN"
    }
  }
  ```

### `POST /api/v1/auth/login`
Authenticates existing users.
- **Request Body:**
  ```json
  {
    "email": "jane@acme.com",
    "password": "Password123!"
  }
  ```

## 2. Tasks & Approvals

### `GET /api/v1/tasks`
Lists all tasks for the user's organization.
- **Query Parameters:** `status` (`READY_FOR_REVIEW`, `COMPLETED`), `requires_client_approval` (`true`/`false`)
- **Headers:** `Authorization: Bearer <token>`

### `POST /api/v1/tasks`
Creates a new task.
- **Request Body:**
  ```json
  {
    "title": "Q4 Meta Campaign Creative Approval",
    "description": "Review new video ads for Q4 campaign launch.",
    "priority": "HIGH",
    "due_date": "2026-10-25",
    "requires_client_approval": true
  }
  ```

### `POST /api/v1/tasks/{task_id}/approve`
Approves a task deliverable.
- **Request Body:** `{"comment": "Looks great!"}`

### `POST /api/v1/tasks/{task_id}/request-changes`
Requests changes on a deliverable.
- **Request Body:** `{"comment": "Please update logo color to dark blue."}`

## 3. Analytics & Meta Integration

### `GET /api/v1/analytics/overview`
Retrieves aggregated ad performance metrics (Spend, ROAS, Impressions, Clicks, Conversions).

### `GET /api/v1/meta/connection`
Checks connection status of the organization's Meta Ad Account.

### `GET /api/v1/meta/connect/url`
Generates Meta OAuth login URL.
